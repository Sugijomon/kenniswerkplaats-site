# Kenniswerkplaats.nl

Basissite in Astro. Inhoud staat in `src/data/`. Zie `CLAUDE.md` voor de afspraken.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # bouwt naar dist/
```

## Aan de slag
1. Maak op GitHub een privé-repo `kenniswerkplaats-site` en push deze map.
2. Koppel de repo in Vercel (framework wordt automatisch herkend als Astro).
3. Start taken in een cloud-sessie op claude.ai/code op deze repo; elke PR krijgt een preview.
4. Review lokaal met Codex (`AGENTS.md` bevat de criteria).
